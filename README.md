MiniYT: a minimalist YouTube player for old and low-power computers. It’s small, fast and uses very few resources. It remembers your playlist progress by saving a tick on each video you’ve watched, which makes it handy for working through courses and tutorials.

How to run: Download MiniYT.exe and run it. There is no installer. On the first start the app downloads its video player (mpv) by itself, so you need an internet connection.

Windows warning: The file isn’t digitally signed (no certificate), so Windows SmartScreen shows a warning. Click More info → Run anyway.

Safety: On VirusTotal, 2 of 71 engines show a generic heuristic warning (a false positive) and the other 69 report the file as clean. The source code is open on GitHub, so you can read it or build the exe yourself.
